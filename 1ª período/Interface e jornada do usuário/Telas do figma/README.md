# Sistema de Monitoramento de Rede

## Resumo

Projeto de criação de uma interface para um sistema de monitoramento de rede, desenvolvido com foco na organização das informações e na experiência do usuário.

O sistema tem como objetivo permitir que o usuário acompanhe informações relacionadas à sua conexão de rede, facilitando a visualização de possíveis oscilações e o gerenciamento da sua conta.

As telas foram desenvolvidas no Figma, buscando criar uma interface simples, intuitiva e de fácil utilização.

## Telas desenvolvidas:
- Tela de login
- Tela de oscilação de rede
- Tela Minha Conta
